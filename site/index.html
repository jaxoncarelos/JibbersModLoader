Mods for the mountain.

Install the loader once. Then pick mods from Options > Mods in the game, and they update by themselves. Every mod is open source and reviewed here before it reaches anyone.

Download the loader Browse mods

Download

Get JibbersModManager.zip. It's small: the rest downloads on first launch.

2

Extract beside the game

Close Jibbers, then put version.dll and JibbersMods next to Jibbers.exe. In Steam: right-click Jibbers, Manage, Browse local files.

3

Pick mods in game

Open Options > Mods, enable what you like, and restart. Updates arrive at startup.

Why trust it

One repository, reviewed code

Source, not downloads

Every mod's code lives in the loader's repository. Builds are made from that code by GitHub Actions, never uploaded by hand.

Read before it ships

Submissions and updates arrive as pull requests. A person reads the code; nothing is published until it's merged.

Signed updates

The loader only installs files from the signed catalog, and warns you about any mod DLL that didn't come from it.
