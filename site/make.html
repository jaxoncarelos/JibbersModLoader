Make a mod

Write it in C#, play it in Jibbers.

Mods are ordinary C# projects built against the Jibbers SDK. It gives you the game's camera, input, physics events, settings menus, overlays and even Steam parties, without touching the game's files.

1 · Get the SDK

Download JibbersCSharpSDK.zip: the SDK, a project template, examples and the source of every public mod. You need the .NET 8 SDK.

2 · Start from the template

Copy template/MyMod, rename it, and give your mod a unique Id. A whole mod can be this small:

public sealed class NightLightsMod : JibbersMod
{
    public override string Id => "night_lights";
    public override string Name => "Night Lights";

    [KeyBinding("Toggle lights", Key.F6)]
    public Key ToggleKey { get; private set; }

    public override void OnLoad() =>
        Input.OnPressed(() => ToggleKey, () => Log("Lights!"));
}

Build in Release and the DLL installs into the game's JibbersMods/cs folder for testing.

3 · Test it

Put tests in a <Folder>.Tests project beside your mod: static methods marked [Test], using Assert, like the public mods under mods/cs. Keep game calls behind small adapters so the rules of your mod run without the game.

4 · Submit

Push it to a public GitHub repository (or zip the source) and use Submit a mod. Keep to plain C# source: no DLLs, NuGet packages or build scripts. Everything that runs in players' games must be reviewable in the submission.
