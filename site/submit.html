Needs a GitHub account.
What to send
  • One C# project made from the SDK template, with one class deriving from JibbersMod and a constant Id.
  • Plain source: .cs, docs, JSON and images. Unity asset bundles are allowed and reviewed.
  • A <Folder>.Tests project beside it, if you can. The bot writes a basic one if not.
Not accepted
  • DLLs, executables, scripts or other binaries.
  • NuGet packages or references besides the Jibbers SDK: include the code you need.
  • Custom build steps. Your project file is replaced by the repository's template.
What happens next
  • The bot builds and tests your mod against the SDK players run, then opens a pull request with a report.
  • A maintainer reads the code. Native calls, processes, networking and file deletion get a closer look.
  • Once merged, your mod is published and appears in Options > Mods.
  • Updates work the same way. Only you (and maintainers) can update your mod.
