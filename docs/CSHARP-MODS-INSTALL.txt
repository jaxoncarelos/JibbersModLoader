C# gameplay mods: Atmosphere, Rewind (Reshred), FPV

Close Jibbers and install JibbersCSharp.zip first.
Extract this mod ZIP into a separate folder, then run its installer:

  powershell -ExecutionPolicy Bypass -File .\install.ps1

For a different game location, add -GameDir "D:\Games\Jibbers Playtest".
The installer backs up matching native/old managed DLLs, installs the C# mods,
keeps their public update subscriptions, and adopts the copied bundles for future updates.
Settings, unrelated local mods and your automatic-update preference stay unchanged.
Use the installer rather than merging duplicate native and managed mod copies.

The public automatic-update catalog distributes these C# mods and their shared runtime.
With automatic updates enabled, updates apply at game startup. Existing manager installations
receive selected C# mods automatically; there is no need to install these ZIPs again.

FPV: F9 or L3+R3 take off/land; F10 or LB mode; middle mouse or RB lock
(hold to release); Home or Y return. All keys and flight settings are in Mods.

Log: jibbers_hotload.log beside Jibbers.exe.
Source: https://github.com/jaxoncarelos/JibbersModLoader (GPL-3.0).
