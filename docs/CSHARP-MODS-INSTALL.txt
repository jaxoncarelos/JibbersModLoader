C# gameplay mods: Atmosphere, Rewind (Reshred), FPV

Close Jibbers and install JibbersCSharp.zip first.
Extract this mod ZIP into a separate folder, then run its installer:

  powershell -ExecutionPolicy Bypass -File .\install.ps1

For a different game location, add -GameDir "D:\Games\Jibbers Playtest".
The installer backs up matching native/old managed DLLs, installs the C# ports,
and retires their native update subscriptions. Settings and local-only mods stay.
Do not simply merge this ZIP into a game with the Rust mods still installed:
that would run both implementations and make their hooks/camera controls conflict.

These C# builds are for local acceptance testing. The public automatic-update catalog
still serves the tested Rust gameplay mods. Do not select the same native mods in
the install menu while testing their C# equivalents. Loader updates continue.
Gameplay acceptance in the running game is still required before publishing C# mods.

FPV: F9 or L3+R3 take off/land; F10 or LB mode; middle mouse or RB lock
(hold to release); Home or Y return. All keys and flight settings are in Mods.

Log: jibbers_hotload.log beside Jibbers.exe.
Source: https://github.com/jaxoncarelos/JibbersModLoader (GPL-3.0).
